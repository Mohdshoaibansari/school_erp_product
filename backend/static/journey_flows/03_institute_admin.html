Flow 3 — Institute Admin Journey

← Back to all flows
This flow: Institute Admin logs in → views institution → manages org units (create, move, archive, reactivate) → transitions institution lifecycle. Assumes Flow 2 completed.
Prerequisites: Run Flow 2 first. Stored vars required: ADMIN_ID, CLIENT_SLUG, INST_ID.

Steps

1Login as Institute Admin
2View own Institution

Org Unit Management

3Fetch OrgUnit Type IDs
OrgUnits require type_id (FK to org_unit_type lookup). Fetch types via our lookup endpoint.
Extracts IDs by name, not by index — robust against lookup table reorderings.
4Create root OrgUnit (Primary School)
5Create child OrgUnit (Grade 5)
6List OrgUnits (subtree)
Should show root + Grade 5.
7Create second root OrgUnit (Secondary School)
8Move Grade 5 from Primary to Secondary
Move OrgUnit to new parent. Subtree moves with it.
Verify with subtree listing afterwards — Grade 5 should now appear under Secondary School.
9Archive Grade 5 (soft delete)
10Reactivate Grade 5

Institution Lifecycle Management

11Deactivate Institution (active → inactive)
Pause for term break.
12Reactivate Institution (inactive → active)
✅ Flow 3 complete. Institute Admin can manage org units (create, move, archive, reactivate) and transition the institution lifecycle within their school.
