Flow 9 — Platform Bootstrap (Full E2E)

← Back to all flows
This flow: Combines Flow 1 + Flow 2 into a single end-to-end bootstrap. From zero state to a fully operating school with users. Useful for demos and full regression.
Prerequisites: Backend running. SUPABASE_SERVICE_ROLE_KEY set on index page. A platform owner user exists in Supabase Auth.

Steps

This flow uses a different client name ("Sunrise International") so you can run it independently.
1Platform Owner Login
2Create Client — Sunrise International
3Activate Client
4Bootstrap Director in Supabase Auth
5Insert Director into app_user + assign role
6Director Login
7Get Institution Type
8Create + Activate Institution
9Create Admin User + Activate
10Admin Login — Verify
✅ Flow 9 complete. Full bootstrap from zero to a working school with an admin user. Sunrise International is now fully operational. Use the BOOT_* env vars to continue testing flows for this client.
