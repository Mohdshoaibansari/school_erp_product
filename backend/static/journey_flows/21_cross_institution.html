Flow 21 — Cross-institution Role

← Back to all flows
This flow: Cross-institution role (e.g., Regional Manager) logs in → reads client info → lists institutions across the client → reads org units → tests permission boundaries.
Prerequisites: Run Flow 2 first. Stored vars required: CLIENT_SLUG, CLIENT_ID, INST_ID, CROSS_INST_EMAIL, CROSS_INST_PASSWORD.

Login

1Login as Cross-institution Role

Read-Only Access

2Read Client Info
3List Institutions (cross-institution view)
4Read Institution
5List Org Units

Academic Structure (Read-only)

6List Academic Years (across institutions)
7View Academic Structure for Institution

Failure Scenarios

8Cross-institution tries to create institution (should FAIL)
Expected: 403 Permission denied. Cross-institution has only read permissions.
9Cross-institution tries to update institution (should FAIL)
Expected: 403 Permission denied. Cross-institution has no institution.update.
10Cross-institution tries to create user (should FAIL)
Expected: 403 Permission denied. Cross-institution has no user.* permissions.
11Cross-institution tries to manage org units (should FAIL)
Expected: 403 Permission denied. Cross-institution has no org_unit.create.
12Cross-institution tries to manage fees (should FAIL)
Expected: 403 Permission denied. Cross-institution has no fee.* permissions.
✅ Flow 21 complete. Cross-institution role can read clients, institutions, org units, and academic structure across the client. Cannot create or modify any data.
