Flow 23 — Employee Module

← Back to all flows
This flow: Admin creates an employee → activates → manages lifecycle (suspend, deactivate, terminate) → verifies config validation and authz boundaries. Demonstrates the full Employee business module (D1–D14).
Prerequisites: Run Flow 2 first. Stored vars required: CLIENT_SLUG, INST_ID, ADMIN_EMAIL, ADMIN_PASSWORD.

Login

1Login as Admin

Employee CRUD

2Create Employee (status = Hired)
Creates an employee linked to a person. Auto-generates employee_no. Initial status is Hired.
POST /api/v1/employees body: { "person_id": "$PERSON_ID", "employment_type": "FULL_TIME", "department": "Mathematics", "designation": "Teacher", "joining_date": "2026-04-01" }
Expected: 201 with employment_status: "Hired", auto-generated employee_no (e.g. EMP-A1B2C3-000001).
3List Employees
Lists all employees for the institution. Supports filtering by status, type, department, designation.
4Get Employee by ID
5Update Employee (department + designation)
Department updated from Mathematics → Science.

Lifecycle Transitions

6Activate Employee (Hired → Active)
Expected: employment_status: "Active".
7Suspend Employee (Active → Suspended)
8Re-activate (Suspended → Active)
9Deactivate (Active → On-Leave)
10Re-activate (On-Leave → Active)
11Terminate Employee (Active → Resigned)
Terminal transition. Cascades to archive the linked app_user account at this institution.
Expected: employment_status: "Resigned". The linked app_user at this institution is archived.

Validation & Authz Boundaries

12Cannot activate a terminal employee (should FAIL)
Expected: 400 Invalid transition: Resigned → Active.
13Invalid department rejected (should FAIL)
Department must be in the configured employee.departments list.
Expected: 400 Department 'Astrophysics' is not in the allowed list.
14Invalid employment_type rejected (should FAIL)
Expected: 422 validation error.
15Teacher tries to create employee (should FAIL)
Teacher has employee.read only, not employee.create.
Expected: 403 Permission denied. Teacher has employee.read only.
