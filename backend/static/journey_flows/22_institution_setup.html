Flow 22 — Institution Setup

← Back to all flows
This flow: Create all user types (Principal, HOD, Staff, Parent) + set up academic structure (AcademicYear, enrollment, teacher assignment). Completes the institution setup started in Flow 02.
Prerequisites: Run Flow 02 first. Stored vars required: CLIENT_SLUG, INST_ID, ADMIN_EMAIL, ADMIN_PASSWORD, TEACHER_ID, STUDENT_ID, PRINCIPAL_EMAIL, HOD_EMAIL, STAFF_EMAIL, PARENT_EMAIL.

Login

1Login as Admin

Create Users

2Create Principal
Creates a Principal user for the institution.
3Assign Principal Role
4Create HOD (Head of Department)
5Assign HOD Role
6Create Staff
7Assign Staff Role
8Create Parent
9Assign Parent Role

Academic Structure

10Create AcademicYear (from template)
Creates academic year "2025-26". Template auto-generates GradeLevels 1-12, Classes, Sections, Subjects.
11View Academic Structure
Get the full structure — terms, grade levels, classes, sections, subjects.

Enrollment & Teacher Assignment

12Enroll Student in Section
13Assign Teacher to Subject
14Transition AcademicYear to Active
Activates the academic year. Previous year (if any) is auto-closed.

Failure Scenarios

15Try to create duplicate AcademicYear (should FAIL)
Expected: 400 Bad Request. Duplicate year name for same institution.
16Try to transition closed year (should FAIL)
Expected: 400 Bad Request. Active → planning is not a valid transition.
17Try to enroll student without permission (should FAIL)
Login as Teacher and try to enroll a student.
Expected: 403 Permission denied. Teacher has enrollment.read but NOT enrollment.create.
✅ Flow 22 complete. Institution now has all user types (Admin, Principal, HOD, Teacher, Staff, Student, Parent) and academic structure (year, enrollments, teacher assignments).
