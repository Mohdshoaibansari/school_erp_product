Flow 5 — Student Journey

← Back to all flows
This flow: Student logs in → views active homeworks → submits homework → views grades. Assumes Flow 4 completed (homework exists, may or may not be graded).
Prerequisites: Run Flow 2 (create student) and Flow 4 (create homework) first. Stored vars: CLIENT_SLUG, STUDENT_ID, HOMEWORK_ID.

Steps

1Login as Student
2View Active Homeworks
3Submit Homework
If you already submitted in Flow 4, this will create a second submission OR return an error if one-submission-per-homework is enforced.
4View My Submissions
Student should see only their own submissions (tenant + ownership filter).
5View My Grades
If teacher has graded the submission (Flow 4 step 6), you'll see the score and feedback here.
6Try creating homework (should FAIL)
Verify student CANNOT create homework — permission denied.
Expect 403 Permission denied.
✅ Flow 5 complete. Student can view homeworks, submit, and view grades — but cannot create homework.
